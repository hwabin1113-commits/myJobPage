# myJobPage — 인증 프로젝트 접수·진행현황 대시보드

> 교육용 가상 데이터 기준 — 실제 업무 시스템 아님

스탠다드뱅크 시험·인증 프로젝트의 접수·진행현황을 보는 Streamlit 대시보드입니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 주요 기능

- 기준일 선택(기본 2026-10-23)과 시험분야·적용규격·담당엔지니어·진행상태·시료상태 다중 선택 필터
- 진행상태·일정상태 요약 카드, 시험분야별 막대그래프, 진행상태 비율 도넛 차트
- 잔여일수(완료예정일 − 기준일)와 일정상태 표시, 지연 후보 행 강조
- 시험분야 등록·이름 변경·삭제(사용 중인 분야는 재분류 후 삭제)
- 전체 목록 / 필터 결과 Excel(.xlsx) 다운로드 — 프로젝트목록·상태별집계·담당자별집계·분석조건 시트
- 시험 자원(EMC 챔버 A/B, RF 차폐실) 상태 카드 — 현황 조회용
- 의뢰번호별 상세조회와 담당자 메모 수정

변경 내용(시험분야·메모)은 브라우저 세션(session_state)에만 저장되며 원본 CSV는 수정하지 않습니다.

## 데이터

`data/SB_project_demo.csv`, `data/SB_resource_demo.csv` (교육용 가상 데이터).
프로젝트 CSV가 없으면 화면에서 업로드할 수 있습니다.
